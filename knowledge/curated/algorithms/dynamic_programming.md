# 动态规划

## 核心定义
动态规划（Dynamic Programming，DP）通过保存子问题的解，避免重复计算，适合具有重叠子问题和最优子结构的问题。

## 四步方法
1. 定义状态：`dp[i]` 或 `dp[i][j]` 表示什么。
2. 写状态转移：当前状态如何由更小状态得到。
3. 初始化边界：最小子问题的答案。
4. 确定遍历顺序：保证依赖状态已经在当前状态之前计算。

## 示例：爬楼梯
`dp[i] = dp[i-1] + dp[i-2]`，`dp[0] = 1`，`dp[1] = 1`。

## 常见错误
- 状态定义不完整，导致转移无法覆盖所有情况。
- 忘记初始化或边界条件。
- 遍历顺序错误，使用了尚未计算的状态。

## 练习
分别实现斐波那契、0/1 背包和最长公共子序列，并分析时间和空间复杂度。
