## 栈与队列

栈是后进先出（LIFO）结构，Python 中可用 list 模拟：
```python
stack = []
stack.append(1)  # push
stack.pop()      # pop, 返回并移除最后元素
```

队列是先进先出（FIFO）结构，推荐使用 collections.deque：
```python
from collections import deque
queue = deque()
queue.append(1)      # 入队
queue.popleft()      # 出队
```
