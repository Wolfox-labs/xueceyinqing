## 字符串运算符（a="Hello", b="Python"）

- `+` 字符串连接：a + b = 'HelloPython'
- `*` 重复输出：a * 2 = 'HelloHello'
- `[]` 索引获取字符：a[1] = 'e'
- `[:]` 截取字符串：a[1:4] = 'ell'
- `in` 成员运算符：'H' in a = True
- `not in`：'M' not in a = True
- `r/R` 原始字符串：print r'\n' 输出 \n（不转义）
- `%` 格式字符串
