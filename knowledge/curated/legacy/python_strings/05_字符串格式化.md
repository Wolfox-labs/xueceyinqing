## 字符串格式化

常用格式化符号：
- %c：格式化字符及其ASCII码
- %s：格式化字符串
- %d：格式化整数
- %u：格式化无符号整型
- %o：格式化无符号八进制数
- %x/%X：格式化无符号十六进制数
- %f：格式化浮点数，可指定精度
- %e/%E：科学计数法格式化浮点数

辅助指令：`*` 定义宽度/精度，`-` 左对齐，`+` 正数前显示加号，`0` 前填充0

示例：
```python
print "My name is %s and weight is %d kg!" % ('Zara', 21)
# 输出：My name is Zara and weight is 21 kg!
```
