## 身份运算符

- `is`：判断两个标识符是否引用自一个对象，类似 id(x) == id(y)
- `is not`：判断两个标识符是否引用自不同对象

is 与 == 的区别：
- is 用于判断两个变量引用对象是否为同一个（同一块内存空间）
- == 用于判断引用变量的值是否相等

```python
a = [1, 2, 3]
b = a
b is a   # True
b == a   # True
b = a[:]
b is a   # False
b == a   # True
```
