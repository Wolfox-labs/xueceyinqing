## 算术运算符

Python 支持以下算术运算符（假设 a=10, b=20）：
- `+` 加：a + b = 30
- `-` 减：a - b = -10
- `*` 乘：a * b = 200
- `/` 除：b / a = 2
- `%` 取模：b % a = 0
- `**` 幂：a**b 为 10 的 20 次方
- `//` 取整除（向下取整）：9//2 = 4, -9//2 = -5
