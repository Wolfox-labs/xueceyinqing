## 赋值运算符

- `=` 简单赋值：c = a + b
- `+=` 加法赋值：c += a 等效于 c = c + a
- `-=` 减法赋值：c -= a
- `*=` 乘法赋值：c *= a
- `/=` 除法赋值：c /= a
- `%=` 取模赋值：c %= a
- `**=` 幂赋值：c **= a
- `//=` 取整除赋值：c //= a
