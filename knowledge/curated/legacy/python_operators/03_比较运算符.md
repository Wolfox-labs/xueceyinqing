## 比较运算符

假设 a=10, b=20：
- `==` 等于：(a == b) 返回 False
- `!=` 不等于：(a != b) 返回 True
- `<>` 不等于（Python3已废弃）
- `>` 大于：(a > b) 返回 False
- `<` 小于：(a < b) 返回 True
- `>=` 大于等于：(a >= b) 返回 False
- `<=` 小于等于：(a <= b) 返回 True
