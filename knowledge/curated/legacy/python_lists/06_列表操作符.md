## 列表操作符

- len([1, 2, 3]) = 3  # 长度
- [1,2,3] + [4,5,6] = [1,2,3,4,5,6]  # 组合
- ['Hi!'] * 4 = ['Hi!','Hi!','Hi!','Hi!']  # 重复
- 3 in [1, 2, 3] = True  # 成员判断
