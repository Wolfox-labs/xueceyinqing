## 列表切片

切片语法：[起始:结束:步长]
```python
s = 'abcdefg'
s[:3]      # 'abc' - 从开头到索引2
s[3:]      # 'defg' - 从索引3到结尾
s[::-1]    # 'gfedcba' - 逆序
s[::2]     # 'aceg' - 间隔一个字符
s[6:2:-2]  # 'ge' - 从索引6逆向到索引2，间隔2
```
