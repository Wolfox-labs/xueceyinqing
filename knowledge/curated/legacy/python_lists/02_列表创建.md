## 列表创建

列表是Python中最常用的数据类型，用方括号[]定义，数据项不需要相同类型：
```python
list1 = ['physics', 'chemistry', 1997, 2000]
list2 = [1, 2, 3, 4, 5]
list3 = ["a", "b", "c", "d"]
```
