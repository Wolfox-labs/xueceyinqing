## 数值类型

Python 支持四种数值类型：
- int（有符号整型）：10, -786, 0x69（十六进制）
- float（浮点型）：0.0, 15.20, -21.9, 32.3e+18, 70.2E-12
- complex（复数）：3.14j, 45.j, 9.322e-36j, .876j

注意：long 类型只存在于 Python 2.x，Python3.x 中已使用 int 替代。Python 支持复数，用 a+bj 或 complex(a,b) 表示。
