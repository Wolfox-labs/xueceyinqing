## 列表和元组

列表是可变序列，用方括号 [] 定义，支持增删改查：
```python
fruits = ['apple', 'banana', 'orange']
fruits.append('grape')
fruits[0] = 'pear'
```

元组是不可变序列，用圆括号 () 定义：
```python
point = (3, 4)
```
