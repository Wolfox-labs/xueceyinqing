## 字典和集合

字典是键值对集合，用花括号 {} 定义：
```python
student = {'name': '张三', 'age': 20, 'score': 95}
print(student['name'])
```

集合是无序不重复元素的集合：
```python
unique_nums = {1, 2, 3, 3, 2}  # 结果为 {1, 2, 3}
```
