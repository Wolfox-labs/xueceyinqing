## 变量和数据类型

Python 是动态类型语言，变量无需声明类型。基本数据类型包括：
- int: 整数，如 42, -10, 0
- float: 浮点数，如 3.14, -0.5
- str: 字符串，用单引号或双引号括起，如 'hello', "world"
- bool: 布尔值，True 或 False
- None: 空值
