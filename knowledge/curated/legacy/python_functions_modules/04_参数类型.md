## 参数类型

- 必备参数：须以正确顺序传入，数量必须匹配
- 关键字参数：使用参数名匹配，顺序可不同
```python
printinfo(age=50, name="miki")
```
- 默认参数：调用时未传入则使用默认值
```python
def printinfo(name, age=35):
    ...
```
- 不定长参数：`*varname` 存放所有未命名变量参数（元组）
```python
def printinfo(arg1, *vartuple):
    print arg1
    for var in vartuple:
        print var
printinfo(70, 60, 50)  # 输出 70, 60, 50
```
