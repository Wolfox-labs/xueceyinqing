## 定义函数

```python
def functionname(parameters):
    "函数文档字符串"
    function_suite
    return [expression]
```
- 以 def 关键词开头，后接函数名和圆括号
- 参数放在圆括号中
- 函数内容以冒号起始，缩进表示代码块
- return 结束函数，不带表达式返回 None
