## 变量作用域

- 全局变量：定义在函数外，整个程序可访问
- 局部变量：定义在函数内，只能在函数内部访问
- 使用 global 关键字在函数内声明全局变量：
```python
globvar = 0
def set_globvar():
    global globvar
    globvar = 1
```
