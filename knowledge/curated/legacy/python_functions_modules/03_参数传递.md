## 参数传递

Python中类型属于对象，变量无类型。参数传递分为：
- 不可变类型（strings, tuples, numbers）：类似值传递，修改不会影响外部变量
- 可变类型（list, dict）：类似引用传递，修改会影响外部变量

```python
def ChangeInt(a):
    a = 10
b = 2
ChangeInt(b)
print b  # 输出 2，不变

def changeme(mylist):
    mylist.append([1,2,3,4])
mylist = [10,20,30]
changeme(mylist)
print mylist  # [10,20,30,[1,2,3,4]]，已改变
```
