## 多态

不同类可以定义同名方法，实现不同行为：
```python
class Circle:
    def area(self):
        return 3.14 * self.radius ** 2

class Rectangle:
    def area(self):
        return self.width * self.height

def print_area(shape):
    print(f'面积: {shape.area()}')
```
