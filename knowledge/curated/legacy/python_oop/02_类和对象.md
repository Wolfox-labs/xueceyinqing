## 类和对象

类是对象的蓝图，使用 class 关键字定义：
```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        return f'{self.name} says woof!'

my_dog = Dog('Rex', 3)
print(my_dog.bark())
```
