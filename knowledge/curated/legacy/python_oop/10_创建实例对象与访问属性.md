## 创建实例对象与访问属性

Python 实例化类似函数调用，通过 __init__ 接收参数：
```python
emp1 = Employee("Zara", 2000)
emp1.displayEmployee()
emp1.age = 7       # 添加属性
emp1.age = 8       # 修改属性
del emp1.age       # 删除属性
```
也可使用函数访问属性：
- getattr(obj, name[, default])：访问属性
- hasattr(obj, name)：检查是否存在属性
- setattr(obj, name, value)：设置属性
- delattr(obj, name)：删除属性
