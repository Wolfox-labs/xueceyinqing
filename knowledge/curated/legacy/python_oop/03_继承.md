## 继承

子类继承父类的属性和方法，可以重写或扩展：
```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        pass

class Cat(Animal):
    def speak(self):
        return f'{self.name} says meow!'
```

Python 支持多继承，一个类可以继承多个父类。
