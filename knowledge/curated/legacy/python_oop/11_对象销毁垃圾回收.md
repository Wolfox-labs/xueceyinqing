## 对象销毁（垃圾回收）

Python 使用引用计数跟踪和回收垃圾。引用计数变为0时被回收。__del__ 析构函数在对象销毁时调用：
```python
class Point:
    def __init__(self, x=0, y=0):
        self.x, self.y = x, y
    def __del__(self):
        class_name = self.__class__.__name__
        print class_name, "销毁"
```
