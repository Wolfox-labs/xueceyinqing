## 封装

使用单下划线 _ 表示"受保护"属性，双下划线 __ 触发名称改写实现私有属性：
```python
class BankAccount:
    def __init__(self, owner, balance):
        self.owner = owner
        self._balance = balance  # 受保护
        self.__pin = '1234'       # 私有

    def get_balance(self):
        return self._balance
```
