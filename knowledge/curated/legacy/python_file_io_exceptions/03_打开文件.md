## 打开文件

```python
file_object = open(file_name [, access_mode][, buffering])
```
access_mode 模式：
- r：只读（默认），指针在开头
- w：只写，存在则覆盖，不存在则创建
- a：追加，指针在结尾
- r+：读写，指针在开头
- w+：读写，存在则覆盖
- a+：读写追加
- 加 b 表示二进制模式（rb, wb, ab等）
