## 捕获异常示例

```python
try:
    fh = open("testfile", "w")
    fh.write("这是一个测试文件！")
except IOError:
    print("Error: 没有找到文件或读取文件失败")
else:
    print("内容写入文件成功")
    fh.close()
```
