# Python 运算符

## 算术运算符
Python 支持以下算术运算符（假设 a=10, b=20）：
- `+` 加：a + b = 30
- `-` 减：a - b = -10
- `*` 乘：a * b = 200
- `/` 除：b / a = 2
- `%` 取模：b % a = 0
- `**` 幂：a**b 为 10 的 20 次方
- `//` 取整除（向下取整）：9//2 = 4, -9//2 = -5

## 比较运算符
假设 a=10, b=20：
- `==` 等于：(a == b) 返回 False
- `!=` 不等于：(a != b) 返回 True
- `<>` 不等于（Python3已废弃）
- `>` 大于：(a > b) 返回 False
- `<` 小于：(a < b) 返回 True
- `>=` 大于等于：(a >= b) 返回 False
- `<=` 小于等于：(a <= b) 返回 True

## 赋值运算符
- `=` 简单赋值：c = a + b
- `+=` 加法赋值：c += a 等效于 c = c + a
- `-=` 减法赋值：c -= a
- `*=` 乘法赋值：c *= a
- `/=` 除法赋值：c /= a
- `%=` 取模赋值：c %= a
- `**=` 幂赋值：c **= a
- `//=` 取整除赋值：c //= a

## 位运算符
按位运算符把数字看作二进制计算。a=60 (0011 1100), b=13 (0000 1101)：
- `&` 按位与：a & b = 12 (0000 1100)，两个相应位都为1则结果为1
- `|` 按位或：a | b = 61 (0011 1101)，只要有一个为1结果就为1
- `^` 按位异或：a ^ b = 49 (0011 0001)，两对应位相异时结果为1
- `~` 按位取反：~a = -61 (1100 0011)，~x 类似于 -x-1
- `<<` 左移：a << 2 = 240 (1111 0000)，高位丢弃，低位补0
- `>>` 右移：a >> 2 = 15 (0000 1111)

## 逻辑运算符
假设 a=10, b=20：
- `and` 布尔与：如果 x 为 False，返回 False，否则返回 y 的计算值。(a and b) 返回 20
- `or` 布尔或：如果 x 是非 0，返回 x，否则返回 y。(a or b) 返回 10
- `not` 布尔非：not(a and b) 返回 False

## 成员运算符
- `in`：在指定序列中找到值返回 True，否则 False
- `not in`：在指定序列中没找到值返回 True

## 身份运算符
- `is`：判断两个标识符是否引用自一个对象，类似 id(x) == id(y)
- `is not`：判断两个标识符是否引用自不同对象

is 与 == 的区别：
- is 用于判断两个变量引用对象是否为同一个（同一块内存空间）
- == 用于判断引用变量的值是否相等

```python
a = [1, 2, 3]
b = a
b is a   # True
b == a   # True
b = a[:]
b is a   # False
b == a   # True
```

## 运算符优先级（从高到低）
1. `**` 指数（最高优先级）
2. `~ + -` 按位翻转，一元加号和减号
3. `* / % //` 乘，除，取模，取整除
4. `+ -` 加法减法
5. `>> <<` 右移，左移
6. `&` 位与
7. `^ |` 位异或，位或
8. `<= < > >=` 比较运算符
9. `<> == !=` 等于运算符
10. `= %= /= //= -= += *= **=` 赋值运算符
11. `is is not` 身份运算符
12. `in not in` 成员运算符
13. `not and or` 逻辑运算符（优先级最低）
