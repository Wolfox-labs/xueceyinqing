# 数据结构与算法基础

## 数组与链表
数组是连续内存空间，支持 O(1) 随机访问。Python 中的 list 本质是动态数组。
链表通过指针连接节点，插入删除 O(1)，查找 O(n)。

## 栈与队列
栈是后进先出（LIFO）结构，Python 中可用 list 模拟：
```python
stack = []
stack.append(1)  # push
stack.pop()      # pop, 返回并移除最后元素
```

队列是先进先出（FIFO）结构，推荐使用 collections.deque：
```python
from collections import deque
queue = deque()
queue.append(1)      # 入队
queue.popleft()      # 出队
```

## 哈希表
Python 的 dict 和 set 基于哈希表实现，平均 O(1) 的查找、插入、删除。哈希表通过哈希函数将键映射到存储位置，哈希冲突通常用拉链法或开放寻址法解决。

## 树结构
二叉树每个节点最多有两个子节点。遍历方式：
- 前序遍历：根 → 左 → 右
- 中序遍历：左 → 根 → 右
- 后序遍历：左 → 右 → 根
- 层序遍历：按层从上到下、从左到右

二叉搜索树（BST）：左子树所有节点值 < 根节点值 < 右子树所有节点值，平均查找 O(log n)。

平衡二叉树（AVL、红黑树）通过旋转操作维持树的高度平衡，保证最坏情况 O(log n)。

## 排序算法
- 冒泡排序：相邻比较交换，O(n²)，稳定
- 快速排序：分治思想，选基准分区，平均 O(n log n)，不稳定
- 归并排序：分治与合并，O(n log n)，稳定
- Python 内置 sorted() 使用 Timsort，结合归并和插入排序

## 搜索算法
- 线性搜索：逐个比较，O(n)
- 二分搜索：要求有序数组，每次减半，O(log n)
```python
def binary_search(arr, target):
    left, right = 0, len(arr) - 1
    while left <= right:
        mid = (left + right) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

## 时间复杂度速查
- O(1): 常数时间 — 哈希表查找
- O(log n): 对数时间 — 二分搜索、平衡树操作
- O(n): 线性时间 — 遍历数组
- O(n log n): 线性对数 — 高效排序算法
- O(n²): 平方时间 — 双重循环、冒泡排序

## 空间换时间
常用优化策略：用哈希表缓存结果（如斐波那契数列的备忘录法）、预处理前缀和数组加速区间查询。
