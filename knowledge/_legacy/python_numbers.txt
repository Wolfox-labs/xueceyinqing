# Python Number（数字）类型

## 数值类型
Python 支持四种数值类型：
- int（有符号整型）：10, -786, 0x69（十六进制）
- long（长整型，Python2）：51924361L, -0x19323L（Python3中已合并到int）
- float（浮点型）：0.0, 15.20, -21.9, 32.3e+18, 70.2E-12
- complex（复数）：3.14j, 45.j, 9.322e-36j, .876j

注意：long 类型只存在于 Python2.x，Python3.x 中已使用 int 替代。Python 支持复数，用 a+bj 或 complex(a,b) 表示。

## 类型转换
- int(x [,base])：将x转换为整数
- long(x [,base])：将x转换为长整数（Python2）
- float(x)：将x转换为浮点数
- complex(real [,imag])：创建复数
- str(x)：将对象x转换为字符串
- repr(x)：将对象x转换为表达式字符串
- eval(str)：计算字符串中的有效Python表达式并返回对象
- chr(x)：将整数转换为字符
- ord(x)：将字符转换为整数值
- hex(x)：将整数转换为十六进制字符串
- oct(x)：将整数转换为八进制字符串

## math 模块常用函数
导入：import math
- abs(x)：返回数字的绝对值
- math.ceil(x)：返回上入整数，如 ceil(4.1) = 5
- math.floor(x)：返回下舍整数，如 floor(4.9) = 4
- math.exp(x)：返回 e 的 x 次幂
- math.fabs(x)：以浮点数返回绝对值
- math.log(x [,base])：返回对数，如 log(100,10) = 2.0
- math.log10(x)：返回以10为底的对数
- math.max(x1, x2,...)：返回最大值
- math.min(x1, x2,...)：返回最小值
- math.modf(x)：返回整数部分和小数部分（均为浮点型）
- math.pow(x, y)：x**y 运算后的值
- math.round(x [,n])：四舍五入，n为小数位数
- math.sqrt(x)：返回平方根

## 数学常量
- math.pi：圆周率 π
- math.e：自然常数 e

## 随机数函数（random模块）
- random.choice(seq)：从序列中随机挑选一个元素
- random.randrange([start,] stop [,step])：从指定范围内获取随机数
- random.random()：随机生成一个[0,1)范围内的实数
- random.seed([x])：改变随机数生成器种子
- random.shuffle(lst)：将序列所有元素随机排序
- random.uniform(x, y)：随机生成[x,y]范围内的实数

## 三角函数（math模块）
- math.acos(x)：返回反余弦弧度值
- math.asin(x)：返回反正弦弧度值
- math.atan(x)：返回反正切弧度值
- math.cos(x)：返回余弦值
- math.sin(x)：返回正弦值
- math.tan(x)：返回正切值
- math.degrees(x)：将弧度转换为角度
- math.radians(x)：将角度转换为弧度
- math.hypot(x, y)：返回欧几里德范数 sqrt(x*x + y*y)
